# Architecture (React Native + Expo)

## Tech choices
| Area | Choice | Why |
|------|--------|-----|
| Framework | React Native + Expo, TypeScript | Company stack; fastest path |
| Navigation | Expo Router | File-based, simple |
| State | Zustand | Tiny, no boilerplate |
| Persistence | AsyncStorage (via Zustand `persist`) | Settings, last read, bookmarks are small |
| Quran data | Bundled JSON per Surah, lazy `require` | Fast, offline, low memory |
| Lists | `FlatList` | Enough for 286 Ayahs; use `FlashList` only if scrolling is janky |
| Font | `expo-font` + Quran font | Correct diacritics |
| Animation | `react-native-reanimated` | Smooth native-thread animations |
| Graphics | `react-native-svg` | Star badge + geometric pattern |

## Types
```ts
export type Surah = {
  number: number; nameArabic: string; nameEnglish: string; nameTransliteration: string;
  ayahCount: number; type: 'Makki' | 'Madani'; bismillahHeader: boolean;
};
export type Ayah = { n: number; ar: string; tr: string };
export type SurahContent = { number: number; bismillahHeader: boolean; ayahs: Ayah[] };
export type Bookmark = { surah: number; ayah: number; createdAt: number };
export type ThemeMode = 'light' | 'dark' | 'system';
export type Settings = { arabicSize: number; translationSize: number; showTranslation: boolean; theme: ThemeMode };
```
Defaults: arabicSize 28, translationSize 16, showTranslation true, theme 'system'.

## Stores (Zustand + persist to AsyncStorage)
- `settingsStore`: settings + setters.
- `lastReadStore`: `{ surah: number | null, ayah: number | null }`, `setLastRead()`.
- `bookmarksStore`: `bookmarks: Bookmark[]`, `toggle(surah, ayah)`, `remove`, `isBookmarked`.
Wait for store hydration before rendering screens that depend on it (splash stays until hydrated + fonts loaded).

## Data loading
`src/features/quran/data/index.ts` (generated by the script) exports `surahLoaders: Record<number, () => SurahContent>` using `require('./surah_001.json')` per Surah, so a Surah is only loaded when opened. `quranRepository.getSurah(n)` calls the loader. `surahs.json` is imported statically (small).

## Navigation
`/` Home → `/surahs` | `/reader/[surah]?ayah=N` | `/bookmarks` | `/settings`

## Reader behaviour
- `FlatList` data = [banner item, bismillah item (if flag), ...ayahs] (discriminated union type).
- Ayah end-marker: `` `${ar} ﴿${toArabicNumber(n)}﴾` `` rendered inline (marker in primary colour via nested `<Text>`).
- Target Ayah highlight: animated background (primarySoft → transparent over 1.5s) after scroll.
- Translation toggle: use `LayoutAnimation` / reanimated layout transitions so rows resize smoothly.
- Save last read: `onViewableItemsChanged` → first visible Ayah → debounced (500ms) → `lastReadStore`.
- Open at Ayah: `scrollToIndex({index})` after data is ready; implement `onScrollToIndexFailed` (scroll to offset, then retry) because row heights vary.
- Arabic style: `writingDirection: 'rtl'`, `textAlign: 'right'`, `lineHeight ≈ 1.9 × fontSize`, Quran font family.
- Memoize `AyahItem` (`React.memo`) so font-size changes and scrolling stay smooth.
